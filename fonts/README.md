# Wordmark font

Dancing Script variable font, unchanged from the Google Fonts distribution.
Used at weight 500 for the flowing mora suffix in the Memora wordmark.
Locally bundled so the header needs no remote font request.

- Source: https://github.com/google/fonts/tree/main/ofl/dancingscript
- License: SIL Open Font License 1.1; see OFL.txt.
- Original filename: DancingScript[wght].ttf.

No application or model dependency is added.
